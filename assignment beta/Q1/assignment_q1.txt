Aassumptions
• Token growth: context lengthens at every step as history and tool outputs accumulate. For call k (k = 1,
2, …, N), input tokens = 2,000 + 800 × (k − 1). Each call produces 350 output tokens, except the final
call, which produces 600.
• Tool calls: calls 1 to N − 1 each produce exactly one tool call, which is executed before the next LLM
call begins. Call N produces the final answer and makes no tool call.
• Cache-able prefix: the first 1,500 input tokens of every call consist of the system prompt and tool
schemas, and are identical across all calls.
• Retries: each of calls 1 to N − 1 produces an invalid tool call with probability p. When this happens, the
agent repeats that call once with the same input, and the retry always succeeds. Call N is never retried.
• Reasoning mode: run every model in its non-reasoning or lowest-reasoning setting, and state the setting
you used. If a model still generates reasoning tokens in that setting, add them to its output tokens for both
cost and latency, using an average reported by the provider or a cited benchmark source.
• Heatwave traffic: on each of the H heatwave days, traffic rises to 5 × Q, and 35% of that day's queries
arrive between 12:00 and 14:00. Every other day carries Q queries. Assume a 30-day month.
